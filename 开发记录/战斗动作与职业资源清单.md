# 战斗动作与职业资源清单

核对日期：2026-10-27。用途：为本地战斗桌的资源图标、操作格及球形分类树建立资料清单；本清单不代表规则已启用或已自动实现。

范围：BG3部分列跨职业通用的非法术操作、基础武器动作和通用物品操作；职业、种族、剧情及独有装备能力属于条件能力，不能当作人人都有的常规动作。D&D部分以本地《玩家手册2024》的12职业及子职为核心，另列本地新版扩展、旧版兼容扩展和可选资料。普通施法法术位不重复罗列；按用户举例，保留邪术师/本地译名“魔契师”的契约魔法法术位。职业给予的免费施法额度属于资源，仍列出其额度，且与“法术本身的操作列表”分开。

“所有”的口径是下列有来源的清单及其标明的覆盖范围，不包括不存在于当前本地快照的未来内容。UA、第三方和怪物独有能力不并入已核对的正式职业资源；可选资料范围见后文。扫描命中不等于资源逐项核验，不能用文件数量声称覆盖了所有出版物。

## BG3跨职业常规操作

中文为工作名称，英文用于对应游戏资料。消耗是BG3本身的消耗；接入本项目时仍应按所启用的D&D 2024规则重新映射。

| 操作 | 英文 | BG3通常消耗 | 条件或说明 |
| --- | --- | --- | --- |
| 主手近战攻击 | Main Hand Attack | 动作 | 使用装备的近战武器 |
| 远程攻击 | Ranged Attack | 动作 | 装备可用远程武器；BG3普通弹药不要求背包库存，特殊箭矢另行消耗 |
| 徒手打击 | Unarmed Strike | 动作 | 不将职业赋予的附赠徒手攻击混入此项 |
| 投掷 | Throw | 动作 | 选择武器、物品或符合条件的生物 |
| 临时近战武器 | Improvised Melee Weapon | 动作 | 以物件或可举起的生物攻击 |
| 疾走 | Dash | 动作 | 获得额外移动预算 |
| 撤离 | Disengage | 动作 | 避免移动引发借机攻击 |
| 躲藏 | Hide | 动作 | 正式版普通躲藏；特定职业可改用附赠动作 |
| 协助 | Help | 动作 | 帮助符合条件的盟友；具体状态按BG3实现 |
| 蘸取 | Dip | 附赠动作 | 武器接触可蘸取的表面 |
| 跳跃 | Jump | 附赠动作＋通常10尺移动 | 特性可能改变消耗 |
| 推击 | Shove | 附赠动作 | 目标与落点必须符合条件 |
| 副手近战攻击 | Off-Hand Attack (Melee) | 附赠动作 | 双持等条件 |
| 副手远程攻击 | Off-Hand Attack (Ranged) | 附赠动作 | 如双持手弩 |
| 喝药水/药剂 | Drink Potion / Elixir | 通常附赠动作＋物品 | 看具体物品；不是所有可饮用物都按同一模板处理 |

共9项消耗动作的基础操作、5项基础附赠操作；另有上述物品操作模板。物品的每个品种不重复算作一种基础操作。来源：[BG3动作总览]、[BG3躲藏]、[BG3跳跃]、[BG3药水]、[BG3药剂]、[BG3涂层]、[BG3消耗品]、[BG3箭矢]。

另列在快捷栏、但不属于“消耗动作或附赠动作”的项目：

| 项目 | 分类 |
| --- | --- |
| 移动、攀爬、从倒地站起 | 移动预算与状态，具体成本分别校验 |
| 表演 Perform | BG3为免费操作，虽出现在动作总览中，也不能因此标成消耗动作 |
| 借机攻击 Opportunity Attack | 反应 |
| 非致命攻击开关 Toggle Non-Lethal Attacks | 被动开关 |
| 双持联动开关、结束回合、查看目标、切换近战/远程武器组 | 控制或界面操作；不等于施展能力 |

来源：[BG3表演]、[BG3非致命]、[BG3资源]。BG3普通动作总览与分类页不是互相完整覆盖的清单，已用单项页面纠正“Hide遗漏、Perform成本归类”问题。

## BG3基础武器动作

下表覆盖[BG3武器动作]页面的Basic weapon actions部分，共20项。它们由武器种类和熟练等条件授予，通常有短休间使用限制，具体条目优先。

| 消耗类别 | 操作名称 |
| --- | --- |
| 动作，近战 | Backbreaker（击背）、Cleave（顺劈）、Concussive Smash（震荡猛击）、Maiming Strike（致残打击）、Disarming Strike（缴械打击）、Heartstopper（止心）、Lacerate（割裂）、Piercing Strike（穿刺打击）、Rush Attack（突进攻击，另涉及移动）、Topple（绊倒）、Weakening Strike（削弱打击） |
| 动作，远程 | Hamstring Shot（断筋射击）、Piercing Shot（贯穿射击） |
| 附赠动作 | Flourish（花式攻击）、Pommel Strike（剑柄打击）、Mobile Shot（机动射击，需满足先前疾走/撤离条件） |
| 移动预算 | Brace (Melee)、Brace (Ranged)（近战/远程稳固姿态）、Prepare（蓄势） |
| 反应 | Tenacity（坚韧） |

独有武器动作应作为“装备赋予操作”挂载，不能放进所有人的基础操作包。例如Phalar Aluve的Sing/Shriek、Dueller's Enthusiasm、Perfectly Balanced Strike等。此清单没有把武器专属效果、怪物技能、所有职业技能和种族能力伪称为“全部常规动作”。

常规操作的职业变体也应指向原操作：例如盗贼的附赠疾走/撤离/躲藏；武僧的附赠徒手打击、疾风连击、疾步/防御能力。它们需要各自能力授权和资源费用，不能因为都能用附赠动作，就默认向全角色开放。

## 图标与数据项的对应关系

后续界面至少要表达六种资源，而不能只支持“几个彩色小点”：

| 类型 | 例子 | 需要保存的值 |
| --- | --- | --- |
| 数量池 | 狂暴、术法点、圣疗 | 当前量、上限、恢复条件 |
| 骰池 | 卓越骰、灵能骰、治愈之光 | 骰数、骰面、池来源 |
| 保存结果 | 预兆、宇宙预兆、彼岸故事 | 原掷骰结果、是否使用、持续状态 |
| 使用权/冷却 | 动作如潮、神圣干预、免费施法 | 使用次数、触发恢复、剩余日数或LR次数 |
| 库存/活跃名额 | 灵药、魂器、注法物品、炮台 | 具体对象、数量、来源与到期时间 |
| 递增代价/每目标限制 | 超限导能、坚韧狂暴、旧版催眠 | 使用计数、当前DC、相关目标ID或失效条件 |

全角色还可能使用生命骰、英雄激励、专注状态、死亡豁免等通用数据；它们不冒充某个职业独有资源。武艺骰、偷袭伤害骰、武器精通数量及已知法术数量，也不能仅因“有数值”就认作可消耗职业资源。
