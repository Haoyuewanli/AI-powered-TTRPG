# 战斗窗口预览

## 当前版本：预览02（2026-11-04）

用户已确认按五批方案制作：重排战斗操作、可放置参战者白板、2D/3D与底部物品栏、地面层、三维控制与灵敏度。本轮仅制作并修改预览，最终确认后才接入正式程序和打包。

双击本目录的 `打开预览.cmd`，自动启动本机服务并打开浏览器。命令行也可运行 `node serve.mjs --open`。关闭启动终端可停止该次预览。每次启动生成全新演示局面；同次服务运行期间，刷新页面保留已保存修改。临时数据、截图和测试输出全部位于 `开发记录/临时/战斗窗口预览/`，不提交。

根地址是预览02；同一地址加 `/v1` 可查看第一版对照。两版使用不同演示状态，不互相修改。预览02默认进入本机DM工作台，不读取真实角色、真实团或正式存档。

## 使用方式

1. 底部九格是快捷物品栏，点击、滚轮或1～9选择积木并进入放置模式；“全部积木”展开底部目录，可替换当前快捷格。现有11种积木包括1/5尺方块、普通/小型/大型参战者白板、地板、矮墙、圆柱、坡块和楼梯。
2. 2D采用正交俯视；参战者显示与占地一致的圆点，颜色区分阵营。连续点击可连放，同一层同一位置的同种积木不会重复生成。选择工具下，点击物件打开编辑卡；重叠处再次点击切换对象，俯视点不会被同层地板遮住。
3. 白板可先放后填，分别编辑名称、阵营、占地、外观高度和位置。战斗数值折叠，未填即保留未知状态；“填入演示数值”是明确的测试操作，不代表合法完整角色卡。开战入口列出缺项角色，齐全后明确掷先攻。
4. “地面层”可新建、切换和改高度。它是建造基准面，不自动生成实体地板。2D显示当前层；3D可勾选多层，选中层有实线网格，未选层不能放置。默认取最近的有效命中层，可勾选“固定落点到当前层”；预览文字标出层名、层高和位置。层高变化会整体移动所属物件。层高按0.5尺对齐。
5. 3D：WASD前后左右，Q/Shift下降，E/Space上升。右键拖动转向，或点击“鼠标环视”，Esc退出。2D右键平移，Ctrl+滚轮缩放；两种视图均有缩放和归位按钮。控制设置分别调整平移、升降、鼠标转向，立即生效并在当前浏览器保存。输入表单、打开弹窗、失焦和切换模式会停止移动。
6. 战斗时收起建造物品栏，底部只显示当前角色、先攻顺序、生命与移动/动作摘要。支持移动落点确认、武器攻击目标选择与掷骰、疾走、主持裁定、下一回合、结束和记录；操作走既有本地规则核心。顶部撤销最多保留本次服务内最近50步；无效操作不写入演示状态。

## 架构与整合边界

- `scene-model.mjs`：积木目录、场景约束、层与对象编辑。2D/3D共用同一份对象标识和层归属，不各存一份场景。
- `v2-view.mjs`：Three.js显示、射线落点、选中反馈、相机和输入。继续使用本地锁定的Three.js和原方块人物几何，无新增依赖或外部请求。
- `v2.mjs` / `v2.html` / `v2.css`：按阶段组织界面；角色属性只在选中后出现。
- `preview-store.mjs`：演示状态、版本检查、串行原子写入及撤销；在开战时将已完善对象转换为原战斗核心输入，复用核心的掷骰、费用、碰撞与结算，未复制规则。
- `serve.mjs`：只监听127.0.0.1、同源检查、固定文件白名单；两版分别指向临时状态。联机、真实资源导入、文件定位和正式服务关闭入口均不开放。

本轮不接入正式存档、不迁移旧地图、不打包、不新增联机或模型调用。高级职业/法术、完整角色档案、玩家身份与正式权限仍留待最终整合；复杂楼层移动、视线及高差战斗仍由原核心拒绝自动结算并提示主持裁定。当前预览不能被当作完整D&D规则自动化或完整角色编辑器。

场景高度与尺寸遵守现有核心范围；参战者占地宽深为1～30尺整数，地形尺寸/位置和层高按0.5尺对齐。正式层字段、真实旧档迁移、完整操作目录和角色资源映射须在最终确认后接入；不能将预览状态整份覆盖正式存档。旧版前端仅作为对照复用，第二版界面与它分离；后续积木扩展集中在目录和渲染适配，新增机械行为仍只扩展原规则核心。
