# 战斗窗口预览

2026-11-04：用户要求先修改预览，最后确认后才实现、打包。第一版以当前战斗核心为对照基线，不重新决定既有布局。

运行 `node serve.mjs`，打开输出的本机地址。选择“我是DM”进入；玩家演示身份为 `player-1` 或 `player-2`。每次启动生成全新合成局面，刷新页面保留本次演示操作。临时演示文件位于 `开发记录/临时/战斗窗口预览/`，不进入版本记录。

本轮验收：独立入口可用；合成角色可布置和查看行动；宽窄窗口显示可检查。界面修改集中于本目录，确认后才接入正式平台。当前复用正式前端只读文件及规则核心，HTML在响应时添加预览标记，样式覆盖放在preview.css；需要修改交互时再将相应前端模块做设计副本，不复制整套规则。

预览转发仅开放登录、状态、战斗操作、攻击预估、界面偏好和主持包读取。联机、真实资源导入、文件定位、团管理及关闭正式程序接口不开放。后台核心明确指向临时演示目录，不采用默认真实团。此版本尚未模拟平台整体外框，也不代表已验收正式权限、完整规则、第二设备或打包。

可维护性：规则继续由原核心统一处理，预览层只承担入口与样式；后续正式前端变化也会影响这份基线，因此正式接入前应按最终预览逐项核对，不整份覆盖正式核心。

实际检查：2026-11-04，浏览器通过DM登录、3D画布显示、演示棋子位置修改与状态读取核对；1440×900、1024×768、390×844无整页横向溢出，截图已目视检查。预览拒绝联机、文件、选团和关闭程序请求，拒绝跨来源请求与非白名单文件；检查期间无页面脚本错误或外部网络请求。没有执行完整战斗规则回归，本轮未改规则。小屏沿用原界面的纵向排列。
