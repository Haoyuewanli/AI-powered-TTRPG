# 目录驱动交互预览

用于核对2026-10-30问卷中的模组、资源主窗体验。运行于独立的本机地址，所有团、角色、资源正文及交互状态均为演示；仅风骸岛封面按固定路径只读加载。没有连接正式平台API，也不会写入真实目录或游戏进度。

## 打开

在本目录执行：

    node serve.mjs

终端会显示本机地址，打开该地址即可。默认使用当前工作区的项目目录读取封面；独立工作树没有封面时，可指定：

    node serve.mjs --project-root "D:\\0. Junior-Fall.7\\The_Life\\990. AI跑团尝试\\项目"

端口默认自动选择空闲端口，不占用正式平台。只绑定127.0.0.1，不支持第二设备连接。服务只接受GET/HEAD及固定文件白名单。

## 建议体验顺序

1. 首页选DM，进入模组。浏览“多人短团”的风骸岛，查看演示团概况，再点“继续此团”，核对当前团变化。
2. 切换空分类，查看空态和原设计示例入口；回到风骸岛，试用次级资料入口及仅保存在本页内存的新开团。
3. 进入资源，试用搜索、类型和模组筛选；选择类别卡片，再从资料卡右侧展开阅读MD。
4. 试用打开文件夹和刷新按钮。这些在预览中说明目标路径或模拟重新读取，不会真实启动系统文件夹或搬动资料。
5. 打开外观设置，检查原有颜色、光影、提起、渐变与地面透视控件；可回到原设计示例对照。

四预设在此用于浏览器布局比例预览，未接入正式平台的原生外框适配器。本轮不以此证明或改动Windows窗口尺寸功能。

## 实现与检查

preview-workspace.mjs是正式design-workspace.mjs的设计副本，只用于本次预览的数据与接口调整；样式继续复用正式design-workspace.css。正式实现时应按确认结果局部接线，不能将此副本整份覆盖正式模块。

原始设计通过original.html单独展示，保持旧演示可访问。其他窗口只保留演示或后续范围说明，正式权限、文件管理、跨设备聊天和战斗行为没有在这里实现。

浏览器检查由check.mjs执行，输出进入开发记录/临时，使用独立浏览器和合成状态，拦截外部请求。正式平台与战斗的完整回归留到实际代码接入阶段。
