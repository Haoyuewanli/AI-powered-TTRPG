# 独立掷骰原型

当前完成了不依赖第三方库的判定与本地记录模块。3D 动画尚未接入，不能作为完整骰盘试玩。

在此目录使用 Node.js 20 或更新版本运行：

```powershell
node --test tests/*.test.mjs
```

不需要安装包。2026-10-22 实际使用 Node.js 24.16.0，7 项检查通过，覆盖所有支持骰型的端点、无偏映射、全部 100 种百分骰拆分、错误输入、记录损坏与写入失败。

## 模块边界

- `src/rolls.mjs`：请求校验、安全随机数、正式判定记录和显示用骰子拆分。
- `src/journal.mjs`：通过传入的存储接口保存、恢复并校验最后一次判定。后续界面可以传入浏览器 localStorage；当前尚未运行浏览器存储测试。
- `tests/rolls.test.mjs`：固定输入的规则和故障检查，不调用网络。

后续动画适配层接收已有判定，不自行重新掷骰。更换动画库无需改动随机数和记录格式。

记录格式当前为版本 1。它只是一份技术试验的最后一次判定，不是完整战役存档，也不提供防篡改或多人公平性保证。

保存点与安全回退方法见 [实施与回退说明](../04-掷骰原型实施与回退.md)。第三方依赖尚待安装授权，尚无启动页面。
