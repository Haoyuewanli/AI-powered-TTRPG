# 利用 AI 进行单人跑团

本工作对话的目标：探索如何让一个玩家借助 AI 进行跑团。

资源调研日期：2026-10-21。2026-10-22 已按用户授权试做独立 3D 骰盘，并分步建立本地保存点。该试验不替整个项目选择游戏规则、模型服务或运行框架。

- [资源网站与论坛](01-资源网站与论坛.md)：中文规则入口、模组检索、单人跑团社区和 AI 跑团案例。
- [测试模组说明](02-测试模组说明.md)：已下载的两份官方免费英文单人冒险、来源和测试方法。
- [电脑掷骰效果方案](03-电脑掷骰效果方案.md)：全套 D&D 骰子、模型外观、动画库比较和待确认的验证方案。
- [文件校验记录](测试模组/文件校验.json)：原始文件大小、页数和 SHA-256。
- [掷骰原型实施与回退](04-掷骰原型实施与回退.md)：2026-10-22 开始的独立试验、保存点与检查结果。

- [骰盘测试记录](掷骰原型/测试记录.md)：实际检查结果、性能条件和已知限制。
