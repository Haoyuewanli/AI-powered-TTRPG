# 掷骰原型实施与回退

日期：2026-10-22。用户已要求尝试上次掷骰方案，并保证改动可回退、有扩展路径。这次只是独立技术试验，不替整个跑团项目决定技术栈。

## 范围与验收

本轮沿用上一份方案的三项验证范围：完整常见骰组与正确点数、3D 投掷呈现、动画中断后保留同一判定结果。判定、浏览器本地记录、动画适配层和界面各自独立。

判定模块先使用运行环境内置的安全随机源与无偏整数映射，不依赖动画库。百分骰按十位骰与个位骰拆分。动画只能呈现已经生成的点数，不能悄悄重掷。

先验证一套深色骰盘样式。皮肤商城、完整 D&D 战斗规则、AI 服务、账号及云存档不在本轮范围。

## 怎样安全回退

回退前先查看工作区，保存尚未提交的改动。已提交步骤可以在新的分支查看旧保存点，也可以使用 `git revert` 创建反向提交，保留原历史。不要用强制清理或重置去覆盖未知改动。

浏览器本地判定记录与 Git 分开保存。回退源码不会删除浏览器记录。记录带版本号；不兼容或损坏时应明确提示，不静默当成成功恢复。

## 扩展路径

动画层只接收判定记录并报告完成或失败。后续可以更换动画库、修改配色、加入新界面，不必修改随机源和正式点数。当前只支持简单的同类骰池；复合公式、优势劣势和修正值可在规则层单独增加。
