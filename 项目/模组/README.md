# 本地模组目录

在此按“分类 → 模组”建立文件夹，封面名为`模组封面.png`或`模组封面.jpg`：

```text
模组/
  分类 A/
    模组 A/
      模组封面.png
    模组 B/
      模组封面.jpg
  分类 B/
    模组 C/
      模组封面.png
  cover-crops.json
```

从本地战斗桌选择DM，打开“本地文件 → 管理模组封面”。页面自动读取目录和封面；在资源管理器中增删模组或换封面后，点击“刷新目录”重新读取。页面只读取封面，不读取模组正文。

横竖封面默认完整显示，不拉伸。点“切割封面”调整位置和放大并预览，确认保存后，所有模组的裁切统一写入此目录的`cover-crops.json`；原图不会被改写。完整显示也作为一条显示配置记录。裁切不是战斗操作，不改变团、战斗、骰点或角色资源。

目录同时有PNG/JPG时，优先沿用已记录配置的文件；没有配置时采用PNG。更换封面后须刷新；配置或原图在预览后被改动会拒绝旧保存，避免覆盖外部编辑。坏JSON、较新版本配置和不安全的目录链接不会被自动覆盖或跟随。

此目录内的模组、封面和生成配置不进入Git。备份请复制整个目录；它与战斗正式存档分开。可用服务选项`modulesDir`或启动环境变量`RPG_MODULES_ROOT`指定另一个本地根目录。
