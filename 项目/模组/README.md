# 模组

下一阶段已确认但尚未迁移：共享模组改按“预处理/分类/模组/故事、对话、战斗”集中归档，窗口分类依据这些真实目录，风骸岛之龙归多人短团。以下说明仍是当前可用结构；具体目标与讨论见[产品大纲](../../开发记录/产品大纲.md)“模组与资源窗口：修改想法”。

本目录只分共享预处理与各团：预处理/故事、预处理/对话、预处理/战斗存模板；每个游玩团下也有故事、对话、战斗三个分区。工作区.json在本目录根登记团与活动战斗。

新模组的PDF和封面放进预处理/故事内的独立输入文件夹，再从平台模组页提取候选。自动候选需要核对；风骸岛之龙本轮单独完成了来源页、地图与明确节点核对。新建团不会改共享模板，各团进度互相独立。

真实封面管理识别预处理故事下的模组目录，沿用模组封面.png/.jpg及cover-crops.json。支持旧两层分类读取以便导入，当前新资料不再按单人短团等分类建立顶层目录。原图始终保留，裁切另存。

完整要求、操作顺序和限制见[项目README](../README.md)。所有PDF、图片、调用、群聊和团内存档仅保留本机，不进Git。
