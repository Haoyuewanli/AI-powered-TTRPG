## 五分钟人工检测

1. 断网后打开入口，点“版本说明”，查看版本是否为 `v20260913`。浏览器设置不同可能影响本地页面行为，本轮以 Edge 为检查环境。
2. 点玩家手册、城主指南和怪物图鉴的卡片，确认分别为 2024、2024、2025。再点旧版和合作内容，确认自己能区分来源。资料全部保留，不代表游戏全部启用。
3. 点“职业”“法术与表格”“新版怪物”，看中文、表格和配图是否正常。在三环法术页用 Ctrl+F 查“火球术”；法术在原资料中按环阶合页，不一定有独立标题页。
4. 在搜索框输入“战士 2024”“3环”或“地精”，核对结果路径中的书籍年份；点击结果后使用正文的 Ctrl+F 查具体条文。
5. 从“原始简易目录”再进入同一条目，确认目录跳转；有疑问时将这一页与线上相同路径比较。可在入口勾选抽查项，勾选状态刷新后不保留。

抽查证明这些页面在本机能阅读，不证明全书译文或规则逐条正确。要核对玩法，应另选固定规则样例与原文、勘误对照。

本轮已用 Edge 156 在断网模式验证入口搜索、十个样本和目录过滤后跳转，页面脚本无报错；已目视查看入口截图。样本中的职业、法术和怪物表格正常，但十个样本均无正文配图，尚未逐图验证全书。

## 已知缺口

完整下载证明文件与上游快照一致，不代表上游所有引用正确。静态扫描记录 4,167 次找不到本地目标的引用，涉及 913 个不同目标：其中 3,285 次为正文/目录链接、847 次为 Word 编辑元数据、35 次为图片或其他资源。这些目标不在同一上游文件清单中，没有用空白页掩盖。

另有 38 次远程资源引用，以及可能由脚本动态请求的云端搜索索引。外链网站、外链图片和网络服务没有镜像，断网时不承诺可用。此入口的本地标题与路径搜索不依赖这些服务，但尚无全书全文搜索。

详细缺口和逐文件校验在本机的 `校验明细.json`，静态扫描不检查所有锚点，也不等同于执行全部页面脚本。后续修复应放在单独的派生层，保留原副本便于重核与更新。

## 重新取得或核对

使用已有 Python 3 和 PowerShell，无需安装新依赖。在工作区运行：

```powershell
& '开发记录/工具/取得不全书.ps1'
```

首次从固定版本下载并核对；已有目录则重新核对，不覆盖不匹配文件。只做本地核对可运行：

```powershell
python '开发记录/工具/核对不全书.py'
```

原始全文在本机，排除出 Git；入口、来源、检查摘要和工具纳入 Git。备份整份本地资料时复制本目录；恢复代码版本不会自动恢复被忽略的资料文件。下载与查阅不等于把全书转成了规则程序。
