# 本地跑团平台

当前已接入首页、六项侧栏、与现有战斗的往返、本地对话演示及本机DM模组封面管理。平台复用战斗服务、会话和安全边界，没有新的登录或游戏结算系统。模组连续封面环、正式资源库、真实地图浏览和模组开团仍未接入，页面明确显示建设状态。

成果仍在独立平台工作树，原共享工作区入口尚未合入这些平台代码。独立树不包含被Git忽略的私人存档；检查使用隔离合成目录，运行参数沿用战斗README，不将另一对话正在使用的存档交给旧平台基线做兼容性测试。

## 首页与战斗

从本工作树的固定入口打开后，在首页选择DM或输入玩家名字/ID。登录后首页显示当前团、战斗、阶段及保存状态，点击“继续当前战斗”进入；左侧“首页”可返回。在首页点击“更换 DM / Player”退出当前身份并重新选择，远程玩家仍使用主持的角色邀请。

返回和继续只切换视图，不结束战斗、恢复资源、切换团或退出会话。保存进行中、角色或地形资料有未保存编辑时，先完成原来的保存/放弃流程。离开战斗会取消未提交拖放和相机按键、关闭工具；回到战斗按当前尺寸显示最新正式进度。

左侧顺序为：首页、模组、资源、地图、对话、战斗。首页仅展示当前授权场景，不自动扫描资料或模组目录；Player不能借平台读取DM目录。原团/战斗工具保留在战斗内。

## 对话演示

“对话”提供群聊、两份资料及两幅自绘地图示例。从左侧打开标签，重复打开会定位已有标签；可关闭、拖动排序或拖到另一分屏，也可使用“前移 / 后移”和区域选择、“移至”按钮。标签栏支持左右键、Home和End。

布局包括单屏、左右、上下、四方格、左二右一、左一右二。先选中一个区域，再从左侧打开内容；缩减分屏时标签有序归并。窄屏通过“查看区域”切换查看各分屏，回到宽屏恢复原布局。

消息输入仅在本页演示，不发送给其他设备或AI，不写正式聊天存档。布局切换、关闭后重开标签会保留本页消息和草稿；刷新页面、切换身份或切换团/战斗会回到公共示例。资料和地图均清楚标为示例，没有连接正式资源库或战斗地图。

## 使用

1. 从固定入口打开跑团，以DM进入，选择“本地文件 → 管理模组封面”。
2. 按[模组目录说明](../模组/README.md)放置分类、模组及PNG/JPG封面，点击“刷新目录”读取外部文件变化。
3. 选择模组后点“切割封面”，调整预览并明确保存。也可选择完整显示。原图不变，裁切统一保存到模组根目录的`cover-crops.json`。
4. 返回跑团时沿用原DM会话和已保存进度。

此入口仅本机DM可用；本机玩家和远程邀请均不能读取目录、封面或写配置。目录为空时会显示放置说明。没有封面、图片损坏、配置损坏或版本不支持时会显示原因，不自动修复或覆盖原文件。

横版和竖版默认完整容纳。裁切保存归一化源区域，比例为3:4；保存时同时核对配置和源图摘要。外部编辑或另一窗口先保存会返回冲突，当前草稿保留，需要重新读取和核对。图片方向导致浏览器展示尺寸与文件编码尺寸不一致时，当前版本可完整查看，但需要先另存普通PNG/JPG再裁切；尚未自动处理EXIF方向。

## 配置与接口

服务默认读取与`平台/`同级的`模组/`，也可通过`startApp({modulesDir})`或进程环境变量`RPG_MODULES_ROOT`指定其他根目录。更改服务代码或根目录后，应在原窗口关闭本机程序再启动；启动器会识别没有新工具能力的旧服务，并提示重开。

新增接口只管理素材展示元数据，均需现有本机DM Bearer会话：

- `GET /api/module-covers`：读取分类、模组、封面信息及配置摘要。
- `GET /api/module-covers/image?moduleId=…`：按已发现的模组ID读取其封面；不接受文件路径或URL令牌。
- `POST /api/module-covers`：提交`moduleId`、`expectedConfigRevision`、`expectedCoverRevision`、显示方式及可选裁切区域，校验后原子更新统一JSON。

图片、配置与目录链接均验证本地范围，封面仅PNG/JPG、单张最多16MB，并限制尺寸。图片解码由浏览器完成。未知写锁会保留并提示，确认没有保存进程后再由使用者处理；工具不擅自清除未知文件。

裁切配置与战斗存档、界面资源设置分开。访问目录、浏览封面或保存裁切不调用`/api/action`，不改变团/战斗版本、骰点、资源或地形。原有接口和业务字段保持兼容；健康检查包含封面能力`capabilities.moduleCovers:1`及平台首页能力`capabilities.platformShell:1`，启动器会拒绝复用缺少对应能力的旧服务。

## 检查

在`项目/战斗`中运行：

```powershell
node --test ../平台/tests/module-library.test.mjs tests/module-covers.test.mjs
node tests/module-covers-browser-check.mjs
node tests/platform-browser-check.mjs
node tests/dialogue-browser-check.mjs
```

使用临时合成目录和图片，不读取真实模组或私人存档。浏览器检查沿用现有Codex运行环境中的Playwright与本机Edge，不是产品新增依赖；覆盖实际入口往返、横版图片、裁切落盘、冲突核对和窄屏。
