# 资源

长期资源按角色、NPC、怪物、地图、故事、规则、物品及A～Z归档。程序和原始规则资料分别在本目录的程序、资料下，不进入资源卡片索引。团内变化、聊天和战斗进度位于模组/各团，而不是与共享定义混写。

下一阶段窗口定位为有筛选能力的可视化文件管理器，层级、归属和路径依据真实目录，版本等筛选读取实际JSON，不建立与磁盘脱节的分类。主卡片/抽屉如何接入现有真实文件能力仍在讨论，本轮未改程序。修改想法统一见[产品大纲](../../开发记录/产品大纲.md)。

资料JSON保留稳定ID、来源、规则家族、出版年和启用状态；收录不等于启用。原始全文、生成资源、私人进度不提交Git。

完整目录契约、启动方法及限制见[项目README](../README.md)。
