# 模组预处理

本目录是以后预处理的统一入口，用户于2026-11-02确认。公共代码、框架和提示词保存在此，输入原件与生成资料只保留本机、不提交Git。

- **第零轮：人类准备。** `0. 待处理模组/<模组>/`存放PDF、MD和图片。AI及第一轮程序只读取指定MD与图片，不读取PDF内容，不改原件。
- **第一轮：地图。** 公共程序与工作台在`1. 处理地图/Code/`，规范及启动提示词在`1. 处理地图/`；按MD和实际图像整理地图目录、描述、提词与热点，生成可直接打开的HTML。
- **第二轮：资源。** 后续从模组中识别资源，引用第一轮稳定地图/地点ID，不通过修改第一轮包写入实际HP、战斗或玩家进度。第二轮公共程序、计划规范与提示词现已在`2. 处理资源/`，程序在其Code中；已完成风骸岛非地图资源一批。

正式平台已整合本轮地图工作台、资料库与按角色资源分享；本目录的第一轮共享按钮是占位，不连接玩家或付费模型服务。
