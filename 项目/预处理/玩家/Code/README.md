# 玩家逐级资料

预处理与正式目录均为 `玩家/<玩家>/<角色名-模组>/<01级>/选择.md、能力.md`。目录另有 `索引.json` 保存稳定身份；正式玩家索引的 `linkedPlayerIds` 仅由DM在玩家窗口绑定，不按显示名称猜测身份。玩家档案默认仅DM可读，绑定后所属玩家可读。复制会重建身份并清空复制的玩家绑定。

两个MD使用JSON前置信息，保留 `schemaVersion、id、name、kind、level、status`。固定标题由公共 `player-format.mjs` 定义；能力是对应等级完整快照，选择只记录该级选择、替换、骰点与来源。收录历史卡不等于把旧版、扩展或房规自动应用到当前团。无记录的等级保留待确认，不从高等级卡倒推。

`prepare-player.mjs` 导出建立逐级档案、建立模版与复制核对结果的方法。直接运行只补齐两处模版。`prepareCharacter` 创建缺失的1至20级档案；`publishCharacter` 仅接受尚不存在的正式角色目录，拒绝覆盖。再次校正现有角色须逐文件核对，或通过玩家窗口保存。素材保留在对应等级的 `来源` 子目录，能力MD可用相对路径显示图片。

玩家目录、原卡与派生全文不提交Git。本目录仅保存公共方法和格式规范。
