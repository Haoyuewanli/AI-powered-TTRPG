# 本地开卡与升级

双击`打开工具.cmd`。玩家阅读同一文件夹内的多个TXT，只填写`回答.txt`，保存后双击“继续”。使用步骤见[说明书](说明书.txt)，外部Agent使用同目录的两份提示词。

支持分轮引导和自由填写、单职业1至20级开卡、从本工具完成的角色继续升级。规则采用本地2024核心资料，无新增依赖、无网络请求。运行环境为项目已有Node.js 24。

## 目录

```text
开卡升级/
  打开工具.cmd
  说明书.txt
  提示词-本地Agent.txt
  提示词-聊天助手.txt
  Code/
    library.mjs       读取固定版本本地资料、修正明确的表格格式缺陷、生成TXT库
    rules.mjs         问题定义、成长顺序、数值、能力及法术选择校验
    equipment.mjs     装备、价格、护甲和武器计算
    render.mjs        TXT问卷、资料文件、角色卡及固定格式MD
    store.mjs         草稿、骰点、模式、升级、历史与成果写入
    cli.mjs           菜单与Agent命令入口
    tests/            合成规则用例与文件流程检查
  TXT库/              本机生成，第三方派生全文不提交Git
  存档/<角色ID>/      私人资料不提交Git
    玩家文件/
      回答.txt        含装备受训、完整候选名称及法术参考文件名
      法术候选-<问题名>.txt
      第X轮参考txt/   已完成轮次的参考资料，不含回答和玩家自有笔记
    成果/<等级>/
    历史/
    状态.json
    检查.json
```

TXT库按对象和等级预先生成。当前3477份TXT，覆盖12职业、48子职、16背景、10种族、75专长、391法术和43种附录野兽。相同规则只维护一份来源；各级文件保留完整说明及等级条件，避免分轮流程遮挡全貌。

运行时从同一份固定本地资料生成与角色状态相关的文件，TXT库作为可直接检索的离线资料；修改预制TXT不会改写规则。重新生成不会改源MD。原资料中法师3/4级连行在转换层修复，测试覆盖20级完整成长表。

## 检查与维护

在工作区根目录运行：

```powershell
node --test '项目/程序/开卡升级/Code/tests/*.test.mjs'
node '项目/程序/开卡升级/Code/cli.mjs' build
```

也可在本工具目录运行`npm test`或`npm run build`。合成测试输出集中在工作区`开发记录/临时/开卡升级检查/`。

规则输入是`项目/资源/`中的固定格式MD，来源筛选为2024玩家手册；野兽为其附录B指向的2025图鉴条目。角色保存来源内容摘要与工具规则版本。资料变化时拒绝静默重算旧角色；新增规则或修改计算语义须提升版本并设计明确迁移，不能只改资料摘要绕过检查。

两种填写模式共用`evaluate`，模式只影响问题显示。自由模式保留全部已启用的专长及前置条件。程序按实际获得等级检查属性条件，草稿可缺项，成果必须通过当前已实现检查。已填答案不会因为上游选择改变被静默删除。

每个角色使用互斥锁，状态采用临时文件后重命名写入。发布玩家文件时先保存生成清单，旧文件移入历史，失败可从已保存状态恢复。回答首行的版本用于拒绝旧编辑窗口覆盖新轮次，玩家不需要填写或手动维护它。用户自己放入的其他文件保持原样。

完成当前轮的选择后，旧参考TXT移入`玩家文件/第X轮参考txt/`，旧回答仍入历史。填写轮次独立于文件修订号；缺项重填、切换模式和恢复不增加轮次。归档清单先记录归属，再逐文件移动，恢复时接着完成未结束的归档，不覆盖玩家自建的同名目录。旧版存档缺少轮次时从第1轮起算，不搬迁旧历史。

法术问题以`kind: 'spell'`声明，候选名称、数量和逐题正文均来自校验使用的同一份`options`。装备采购另提供带价格的`candidates`，保留名称乘数量的输入格式。以后新增法术问题沿用该标记即可生成独立参考，不需要维护第二套候选筛选。问卷变化不修改规则版本或来源摘要，已有存档可以正常继续；刷新已有问卷使用“恢复当前文件”，未提交内容仍会保留到历史。

成果的`选择.md`记录开卡路径或本次升级变化，`能力.md`记录当前完整数值和规则说明。格式兼容平台现有MD解析器，但本工具不会自动移动现有玩家目录、修改归属、覆盖平台角色或把战斗状态回写为新卡。需要接入平台时可以在现有玩家管理中建立等级并导入对应MD。

## 自动化边界

程序处理属性生成与加值、逐级专长前置条件、熟练与专精、体质追溯生命值、施法数值、法术名额与来源、法师逐级法术书、法术位、常用资源上限、野兽候选、装备资金和基础攻击/护甲。能力正文保留完整来源规则，战斗中的触发、目标、临时增益和消耗不在这里结算。

普通武器计算不代表所有战斗风格、专长和职业触发条件均已折算进每次攻击。多职业、旧版扩展、外部旧卡自动导入、额外抄写法术书、魔法物品自动配装与房规效果计算未接入。高等级默认普通起始装备；新角色可通过本地配置`extraGoldCp`指定DM已授权的额外铜币金额，不自动套用DM参考奖励表。

问卷分支检查不等于穷尽所有构筑交互。测试只报告实际执行的用例；豆包与Workbuddy提示词按固定命令流程编写，未声称在这些外部应用实跑通过。

后续扩展分别接入资料转换、选择定义及计算，再添加真实规则用例；无需为新旧玩家分别维护规则。新增依赖、外部资料传输及付费服务仍按项目约定另行授权。
