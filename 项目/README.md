# 单人跑团项目

规则目标是 D&D 2024。当前可用的是本地战斗原型、独立骰盘和本地规则资料。战斗原型支持多团/多战斗切换、战前摆局、几何地形、集中线下骰及有记录撤销、屏幕自适应和棋子拖动、玩家先攻收集、同Wi-Fi/线上邀请加入；复杂法术、月德变形等仍由DM明确裁定。

| 内容 | 入口 |
| --- | --- |
| 本地 3D 战斗桌 | 双击工作区最外层的 [打开跑团.cmd](../打开跑团.cmd)，首次操作见 [使用说明](战斗/README.md) |
| 独立 3D 骰盘 | [双击命运骰盘.html](骰盘/命运骰盘.html)，也可运行 `骰盘/启动骰盘.cmd` |
| 不全书资料库 | [本地查阅与快速检测](资料/5E不全书/打开不全书.html) |
| 早期测试模组 | `资料/测试模组/`，含原件及已有译文，全部保留；并非 D&D 2024 原生测试模组 |

战斗桌在 `存档/工作区.json` 记录团列表，每团及每场战斗分别保存JSON进度。原始12级团及首场文件保留原路径，另保留自动前态和最近30步撤销；启动后从文件恢复。长期备份复制整个 `存档/`，操作步骤见战斗使用说明。私人角色卡、怪物资料和战役进度不进入Git。独立骰盘仍只保留上一掷浏览器记录。

NPC 在战斗中选择目标、动作、移动或战术，由主持者或人工决定。本地规则程序只处理已支持动作的权限、骰点、伤害与回合状态，不依赖AI。首轮使用Node.js和现有Three.js；主持交接先采用可人工交换的JSON，实际模型API与外部工具自动接入留待后续实现。

开发文档见 [产品大纲](../开发记录/产品大纲.md)，协作要求见 [项目约定](../项目约定.md)。这里只放项目代码、使用说明、资料和以后实际产生的存档；不预建尚无实现的模块目录。
