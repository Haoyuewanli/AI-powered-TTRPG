# 战局：D&D 2024 跑团平台

“平台文件夹”指本目录。一级子目录只有 **模组** 和 **资源**；程序、规则原始资料与可调用资源分区放在资源内，团内变化归各团自己的模组目录。界面沿用悬浮薄片、留白、光影、封面环、资源抽屉和地图目录。

2026-10-30已确认方向：模组与资源窗口作为依据真实目录的可视化文件管理器；共享预处理调整为“模组/预处理/分类/模组/故事、对话、战斗”，分类初始为单人短团、多人短团、长团，风骸岛之龙归多人短团。分类目录的新资料包读取与甲板试玩现已接通，其他目录可视化交互仍按已确认阶段推进。下面旧目录示例保留兼容说明，不要按旧路径搬回当前b包。修改想法、已确认与待讨论细节统一见[产品大纲](../开发记录/产品大纲.md)的“模组与资源窗口：修改想法”。

首轮交互表单已确认、待实现：选中模组封面先显示已有游玩团，模组资料作为次级入口；模组和资源目录以分类、卡片呈现并提供“打开文件夹”按钮；点击刷新或重新进入目录时同步本地变化。沿用现有外观与动效，完整验收要求见上述产品大纲。

## 打开

2026-10-30问卷已填写，当前先做独立交互预览，再按评审结果实施正式改动。用户自行在外部完成PDF→MD及图片的AI预处理，平台后续按固定契约接收与核对；人工带团时无需AI。已有团的模组/资源基准不自动跟随新版。细粒度发放、跨团已知资源、私信、地图定位提词和流程页等新要求统一见[产品大纲](../开发记录/产品大纲.md)“问卷回答整理与交互预览范围”，尚未因此接通正式权限或改动数据目录。

双击 [打开平台.cmd](打开平台.cmd)，或工作区最外层的打开跑团.cmd。基础程序使用已有Node.js 20+，不安装新依赖。默认优先4198，遇到旧服务自动换空闲端口并记住地址，重开核对程序、资料根及版本后复用；显式--port或RPG_PLATFORM_PORT仍按固定端口严格校验。

命令行启动：

```powershell
node 资源/程序/平台/launcher.mjs --no-browser
node 资源/程序/平台/server.mjs --port 4198
```

第一条后台运行并打印地址；第二条前台运行，Ctrl+C关闭。浏览器关闭不会自动结束后台服务。RPG_PROJECT_ROOT可指定合成测试根；不要用真实进度做破坏性检查。战斗独立入口为资源/程序/战斗/启动战斗.cmd，仍共享同一规则核心。

## 甲板试玩与开发学习

在首页选择DM，点击“浏览本地模组”或侧栏“模组”，会直接显示真实模组清单；首页另有“风骸岛之龙 · 甲板试玩”入口。清单优先列出可用资料包，再列已有游玩团，显示当前候选包的分类和批次；选择2026-10-30-b包，点击“新建甲板试玩团”。原ABC封面环保留在“查看界面示例”，点击“返回本地模组”回到真实清单，浏览不切团。重开时在已有团列表确认同一个试玩团，进入战斗页继续；新建按钮每次明确点击会建立新的独立团。

场景区可以阅读序幕节点和原文行号，填写本段结果及笔记并保存。它不自动打开身份未确认的地图；棋盘是明确标注的甲板示意。训练使用2024规则家族的梅洛，源文2014数据不启用，整本包仍保持candidate。训练战士复用已有PHB2024战士·勇士20级合成测试卡（HP100、AC15、速度30尺、普通近战+11／1d6+5钝击、每攻击动作最多4次），是流程练习数据，不代表完整合法角色卡或平衡遭遇。

点击“进入训练战斗”收起场景区，在战斗区域选择本机DM，逐个核对并保存训练战士和梅洛，再收集先攻、开始。先练移动5尺，观察移动力和保存版本；再试超过剩余移动力，确认被拒绝且原进度不变。普通攻击继续走原规则核心；NPC行动由主持选择，特殊效果沿用人工核对入口。通过“交给主持人”可导出当前交接包、预览和确认提议，不需要模型API。

结束时由主持结束本场，在上方场景区保存结果。看到“已保存”后关闭重开，选择同一团，核对位置、HP、资源、回合、日志和场景记录。战斗与故事分别保存，填写“战斗已结束”文字不代替机械结束操作。未保存的训练记录、聊天和地图草稿会阻止切团或身份；可以明确保存或放弃草稿，保存冲突不会吞掉原文。

“跟着一次移动5尺理解开发”说明界面、统一入口、规则、候选状态和文件保存的职责。首轮学习以能解释规则为什么集中检查、预测拒绝后哪些数据不变、描述保存故障的证据为验收。

## 目录契约

```text
项目/
  README.md、打开平台.cmd
  模组/
    预处理/
      故事/模组ID/          原PDF、原封面、提取文字/图像、预处理.json
      对话/模组ID/          群聊模板
      战斗/模组ID/          遭遇模板
    团目录/
      故事/                模组调用.json、当前.json、地图状态.json、故事进度.json
      对话/群聊目录/       群聊.json、对话.md
      战斗/战斗ID/         战斗调用.json、战斗日志.txt
      战斗/存档/           兼容战斗权威快照及其原内部相对树
    工作区.json            登记所有团与当前战斗，不含剧情正文
  资源/
    角色、NPC、怪物、地图、故事、规则、物品/A...Z/
    程序/平台、战斗、封面工具、骰盘/
    资料/5E不全书/         原始本机快照、来源与校验
```

| 要求 | 约定 |
| --- | --- |
| 资源是长期存储 | 七类按英文或中文拼音首字母A～Z归档，多音字可显式修正。程序和原始资料不进入资源卡片索引；内部管理/导入清单也不当公开资源 |
| 稳定身份 | JSON资源有显式ID；图片等由索引分配稳定ID。模组、团、节点、地图和实例有各自ID字段，改显示名不静默换身份；重名团有稳定后缀 |
| 可复用定义与团内变化分开 | 无名NPC、怪物、物品可跨团引用。当前JSON保存资源基准引用及实例delta，通常HP/环位为相对满额的负值；非数值差异明确绝对覆盖 |
| 单一所属模组 | 地图、对话和内嵌战斗共用模组窗口的选择；其他窗口不改所属团。内嵌战斗旧团切换入口受限，独立战斗保留原管理能力 |
| 聊天持久化 | 消息按时间戳写Markdown；引用使用相对于整个项目根的资源路径，群聊元数据标referenceBase=project，由平台按资源ID打开 |
| DM与Player | DM浏览本地资料。Player仅公共预览，真实接口拒绝访问；正式邀请/受控角色筛选与发放投影尚待衔接。后续筛选包含任一受控角色即可，不能只在前端隐藏秘密 |
| 引用和发放 | 资源右键/更多可引用、开放给某玩家并引用、打开文件夹位置。发放记录不等于已完成跨设备玩家权限，当前范围是整条资源 |
| 本地权威 | 战斗快照仍是机械权威，当前/调用/TXT由外置投影派生，不能编辑delta绕过战斗事务。不会把电脑日期当游戏日，长短休逻辑不在平台重写 |

## 模组预处理到游玩

把新模组PDF和封面放在模组/预处理/故事下的独立输入文件夹。首页选DM，在模组页展开本地文件区、刷新，点击提取预处理候选。程序只调用已安装的本机Python/PyMuPDF，不安装软件、不联网、不调用模型；可用RPG_PDF_PYTHON明确解释器。缺环境、坏PDF、超限或已有输出均保留原件并报出可核对原因。

通用提取会保存PDF副本、逐页文本和嵌入图像候选；自动识别的标题/节点和图片用途都标候选，不能因此认定已理解任意模组。地图的DM/玩家用途、地点、故事条件和资源匹配需要核对；扫描图片没有可靠正文时不假装完成OCR。预处理.json是可检查的本地JSON，不把候选自动当正式剧情。

此前旧批次的风骸岛试跑含79个节点、10张原书地图、74条剧情资源引用；这是旧团的来源说明。当前2026-10-30-b包为74节点、14图、candidate，甲板训练仅核对并使用序幕路径，不能沿用旧批次的整包核对声明。故事描述不嵌等级门槛或固定游玩顺序；原书明确条件、可选内容和来源页另列。地图原JPEG与PDF嵌入图逐字节一致，PNG保持原像素；未核对的热点坐标保持null，不猜门墙。

模组页从预处理新建团并选择，生成独立故事/对话/战斗目录。可选序幕是一只迈罗人鱼登船征税，允许谈判、创意行动或战斗；本轮把它关联到独立的2024规则家族梅洛资源。原书没有该船俯视网格图，战斗准备棋盘明确为可编辑示意。占位玩家角色与敌人都待DM确认，不自动开战、投先攻或扣资源。

选择团后，地图页展开当前模组地图与故事并打开：可浏览主持/玩家原图、缩放平移、从原有右侧目录选地点、查看说明和相关地点引用。探索/敌人已处理/物品已取/笔记各自保存，不联动扣数。故事节点可记录已知/完成；这不代替玩家信息发放。仍可切回公共占位图，原目录及收起按钮保留。

资源支持版本、类型和名称/来源搜索与分页，点击真实资料进入原对话标签分屏。对话支持六种常见布局、拖放换位、资源/地图标签及本地群聊；公共示例与真实消息分别标示。暂未接跨设备实时聊天或AI。

## 规则资源及版本

版本下拉首版为Dungeons & Dragons 2024（龙与地下城2024版）。出版于2025的新版怪物图鉴属于该规则家族，出版年仍如实保留；2014家族及版本待核资料独立标记，不混入当前规则列表。模组描述等无机械版本的引用以custom标示。

本机不全书固定快照共10017个HTML页已逐页登记状态，离线整理出5010个资源JSON，其中2024家族2407。PHB2024含12职业、48子职、391法术、16背景、10物种等；怪物与明确NPC分开，保留来源目录证据。原文收录、解析成功与机械实现是三回事：所有导入资源默认enabled=false，复杂效果仍由主持核对，不自动启用扩展。

每条保存source路径/页标题/锚点/摘要、edition规则家族/年份、availability及解析警告。不同来源同内容保留可追溯分组，不悄悄覆盖。模组中的旧怪物仅存引用描述，不用旧数字覆盖新版。全文和生成资源仅在本机，均不提交Git。

## 维护、迁移与检查

程序分为独立平台、独立战斗与外置适配层。规则、费用、恢复、动作和操作目录仍由战斗核心负责；平台只管窗口、文件、地图浏览与接线。跨窗桥仅canLeave/setVisible/logout确认，精确核对origin，不传秘密状态。换身份/模组会清除旧真实内容、票据和迟到响应；未保存编辑须先处理。

外观保存在资源/程序/平台/.runtime/外观.json，四尺寸各自保存配色、颜色、光影、浮起、渐变与0～20%地面。通过打开平台.cmd启动的独立Edge应用窗口，切换预设会实际调整Windows窗口外框，并在重开时恢复；页面填满窗口客户区。预设为物理像素尺寸，屏幕可用范围不足时，四项按共同2560×1600基准等比缩小并显示实际尺寸。普通浏览器保留页面预览，提示通过独立入口调整窗口。

窗口程序只操作本平台、当前资料根及地址对应的唯一专用Edge窗口，不操作普通Edge、战斗独立窗或其他资料根。最大化时先恢复普通窗口；配色变化不调整窗口。保存冲突不移动窗口，无法确认窗口归属时保留外观并明确提示未调整。窗口缓存位于平台程序.runtime/browser-*，不属于游戏存档。

旧目录通过工作区开发记录/工具/重整项目目录.mjs预检后迁移，先清单和原件备份、再摘要校验、最后写版本标记。未知归属、链接、活锁、不同内容目标都会拒绝。源权威状态字节保留；旧布局原件在开发记录/临时/迁移备份。项目入口按目录迁移.json精准重定向旧显式路径，找不到迁移目标会拒绝启动旧副本。

在资源/程序/平台和资源/程序/战斗内分别运行npm test。浏览器检查用开发机现有Playwright/Edge；证据、合成目录和清理/迁移报告在开发记录/临时。工作树缺本机全文时可用测试专用RPG_REFERENCE_ROOT指向已有资料，不下载全文或削弱断言。实际检查、保存点与未决事项见[整理记录](../开发记录/整理记录.md)和[产品大纲](../开发记录/产品大纲.md)。

当前仍是单活动战斗核心；多DM并发协调、正式Player授权、字段/地图区域发放及任意PDF全自动语义理解尚未完成。私人资料、进度、聊天、备份、缓存和密钥不进Git。不推送、发布、自动调用付费服务或向外发送本地游戏数据。
