# 单人跑团项目

规则目标是 D&D 2024。当前可用的是独立骰盘和本地规则资料，角色、战斗结算、文件存档与主持交接功能尚未实现。

| 内容 | 入口 |
| --- | --- |
| 独立 3D 骰盘 | [双击命运骰盘.html](骰盘/命运骰盘.html)，也可运行 `骰盘/启动骰盘.cmd` |
| 不全书资料库 | [本地查阅与快速检测](资料/5E不全书/打开不全书.html) |
| 早期测试模组 | `资料/测试模组/`，含原件及已有译文，全部保留；并非 D&D 2024 原生测试模组 |

程序运行时必须能将正式进度保存为可备份、可恢复的本地文件；浏览器缓存只能辅助使用。该能力是后续核心的验收要求，当前骰盘仅有上一掷浏览器记录。

NPC 在战斗中选择目标、动作、移动或战术，由主持者或人工决定。本地规则程序只处理动作是否允许、骰点、资源、效果与回合状态；规则运算不依赖 AI。接口和技术栈仍待具体设计。

开发文档见 [产品大纲](../开发记录/产品大纲.md)，协作要求见 [项目约定](../项目约定.md)。这里只放项目代码、使用说明、资料和以后实际产生的存档；不预建尚无实现的模块目录。
