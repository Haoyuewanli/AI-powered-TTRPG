# AI-powered-TTRPG

先支持单人 D&D 2024：本地程序保存状态、校验操作并执行规则结算；故事推进与 NPC 动作选择由可替换的主持者负责。已有首轮本地战斗桌，支持免口令DM/玩家视角、多团多战斗、3D摆局与地形、程序骰/线下骰、基本结算、文件存档及有记录撤销、主持提议预览；复杂法术和月德变形仍需DM裁定。

## 打开已有成果

**日常使用：在本工作区双击 [打开跑团.cmd](打开跑团.cmd)。**它自动启动本地程序、读取已保存进度并打开独立窗口。断网也可使用；电脑重启或程序中断后，再双击同一个入口即可。不必保留某条正在运行的网页链接。
